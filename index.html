Private personal OpenClaw integration

This site documents a private, personal integration operated for hitechlife.com. It is not a public application or commercial service.

Current Google access

The integration is currently limited to user-authorized, read-only access to:

  • Gmail, to read email requested by the authorized user.
  • Google Calendar, to read calendar information requested by the authorized user.

Access occurs only after the user completes Google OAuth authorization. The integration does not send email, modify calendar events, sell data, serve advertising, or track visitors to this site.
