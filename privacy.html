Privacy Policy

Effective September 12, 2026

Scope

This policy applies to the private, personal OpenClaw integration operated for hitechlife.com. The integration is not offered to the general public.

Google user data accessed

After explicit Google OAuth authorization, the integration may access read-only Gmail messages and metadata, and read-only Google Calendar events, calendars, and related metadata. It accesses only data available through the scopes the user approves.

Purpose and use

Google user data is used only to provide user-requested personal assistance, such as reading or summarizing email and reviewing calendar information. The integration does not use Google user data for advertising, profiling, credit decisions, or any unrelated purpose.

Storage and security

OAuth tokens are stored locally in protected credential storage under the control of the operator. Tokens are not embedded in this site or committed to its source repository. Google user data is processed only as needed for the requested function and is not intentionally retained as a separate commercial dataset.

No sale, advertising, or sharing

Google user data is not sold, rented, used for advertising, or shared with third parties. Disclosure may occur only if required by law or necessary to protect security and integrity.

Retention and deletion

OAuth tokens are retained only while authorization is needed. The user may request deletion of locally stored tokens and any retained integration data by contacting the address below. Upon such a request, the operator will delete the applicable local credentials and retained data, subject to limited legal or security obligations.

Revoking access

The user may revoke access at any time through their Google Account security settings. Revocation prevents future API access. The user may also contact the operator to request local token deletion.

Google API Services User Data Policy

The integration's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Site data

This static site uses no analytics, tracking pixels, cookies, external scripts, forms, or user-data collection.

Contact

Questions, deletion requests, or privacy concerns may be sent to rpillartz@gmail.com.
